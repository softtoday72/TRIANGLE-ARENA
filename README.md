# 三角形競技場亂鬥

依據 `三角形競技場亂鬥 — 遊戲規格書.md` 製作的瀏覽器遊戲原型。

## 執行

### 單機

在此資料夾啟動任何靜態檔案伺服器，將根目錄指向 `dist/`。例如：

```powershell
npx serve dist
```

瀏覽器開啟顯示的本機網址即可遊玩。

### 連線對戰

第一次先安裝相依套件，之後只需要啟動伺服器：

```powershell
npm install
npm start
```

啟動後終端機會列出本機與區網網址。用瀏覽器開啟後，設定畫面下方的「多人連線」會直接列出伺服器上的房間：輸入名字後點一間加入，或建立新房間（可取名，不取名就用你的名字）。進房後會顯示可複製的邀請網址，朋友打開後同樣在列表裡點選這一間。

- 預設 port 是 3000，可用環境變數 `PORT` 更改。port 被佔用時，伺服器會提示改用其他 port 的方法。
- 同一個區網內可直接連。第一次啟動時 Windows 防火牆會詢問是否允許 Node.js，需要按允許。
- 要讓區網以外的朋友加入，可用 ngrok 等通道，或把專案部署到有公開網址的主機。
- 用這個伺服器開啟的頁面仍然可以玩單機；沒有加入房間時行為與單機版相同。

目前連線版的範圍：

- 一台伺服器可同時開多個房間（預設上限 30 間，環境變數 `MAX_ROOMS`），每房最多 8 台機體，真人優先、AI 補空位。最後一人離開時房間自動刪除。
- 建立房間的人是房主，負責設定並開始；房主離開時由下一位接手。
- 一輪進行中也能加入：會接手錢最少的那台 AI，連同它的錢和裝備。沒有 AI 可接手時無法加入。
- 商店與結算有倒數（預設 30 秒與 20 秒，環境變數 `SHOP_SECONDS`、`RESULT_SECONDS`），時間到自動繼續。
- 對戰中不能暫停。離開或斷線時機體由 AI 接手；之後可再加入，但同樣是接手錢最少的那台。
- 團戰的隊伍依加入順序自動分配，還不能自選。
- 只有自己的機體有本機預測（按下就動，再與伺服器狀態平滑校正）。射擊、命中和其他機體仍以伺服器為準，延遲高時子彈會晚一點出現。

## 操作

- 方向鍵：移動與轉向
- 空白鍵：射擊
- Z：使用道具
- Esc：暫停（連線時為選單，對戰不會停）

所有主要平衡數值與未決規則的首版預設集中在 `dist/config.js`。

## 武器升級

商店裡再買一次手上的武器就會升級，最高 Lv3，Lv3 之後不能再花錢。死亡或換武器都會回到 Lv1，換掉升級過的武器前會先確認。各武器每一級的效果與價格見規格書「武器升級」一節，數值在 `dist/config.js` 的 `WEAPONS`。

道具已滿時不能再買；用掉一部分時可以補滿，只付缺少的那幾次的錢。

## 檔案分工

- `dist/config.js`：數值與規則設定，瀏覽器與 Node 都能載入。
- `dist/game-core.js`：戰鬥核心（移動、AI、子彈、碰撞、傷害、經濟、勝負）。不碰 DOM、Canvas、鍵盤與計時器，只接收時間步進與每位真人玩家的指令，瀏覽器與 Node 都能執行。
- `dist/app.js`：畫面切換、鍵盤輸入、Canvas 繪圖與粒子效果。單機時每一幀呼叫核心的 `step`；連線時只送出操作意圖，畫出伺服器傳來的狀態，並預測自己機體的移動。
- `server/server.js`：連線伺服器。提供 `dist/` 的檔案並管理多個房間；每個房間用同一份 `game-core.js` 以每秒 60 次推進正式戰鬥，每秒 30 次把狀態傳給房內玩家。敵方地雷與隱形中的敵人不會傳給不該看到的玩家。單一房間出錯只會關閉該房間。
